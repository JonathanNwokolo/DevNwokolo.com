Este é meu portfólio profissional, criado com HTML5, CSS3 e JavaScript puro. O site é totalmente responsivo e apresenta um design moderno com tons de azul e efeitos interativos.

## 🚀 Como Usar

1. **Abrir o site**: Simplesmente abra o arquivo `index.html` em seu navegador
2. **Personalizar**: Edite os arquivos para adicionar suas próprias informações
3. **Hospedar**: Faça upload para GitHub Pages, Netlify ou Vercel

## 📝 Personalização

### Atualizar Informações Pessoais

1. Abra `index.html`
2. Localize as seções que deseja editar
3. Substitua os textos e links pelos seus

### Adicionar Seus Links Sociais

No arquivo `index.html`, encontre as seções `social-links` e atualize os links:

```html
<a href="SEU_GITHUB" target="_blank">
  <a href="SEU_LINKEDIN" target="_blank">
    <a href="SEU_INSTAGRAM" target="_blank"></a></a
></a>
```

### Adicionar Seus Projetos

Na seção de projetos, você pode:

1. Substituir as imagens pelos prints dos seus projetos
2. Atualizar os títulos e descrições
3. Adicionar links para os repositórios GitHub e demo

### Alterar Cores

No arquivo `style.css`, na seção `:root`, você pode personalizar o esquema de cores único:

```css
:root {
  --accent-primary: #a855f7;
  --accent-secondary: #3b82f6;
  --accent-tertiary: #06b6d4;
  --accent-gradient: linear-gradient(
    135deg,
    #a855f7 0%,
    #3b82f6 50%,
    #06b6d4 100%
  );
  /* ... */
}
```

## 🌐 Deploy

### GitHub Pages

1. Crie um repositório no GitHub
2. Faça upload dos arquivos
3. Vá em Settings > Pages
4. Selecione a branch main
5. Seu site estará disponível em: `seu-usuario.github.io/nome-repositorio`

### Netlify

1. Arraste a pasta do projeto para netlify.com/drop
2. Seu site estará online em segundos!

### Vercel

1. Instale Vercel CLI: `npm i -g vercel`
2. Na pasta do projeto: `vercel`
3. Siga as instruções
